# Guide

For gymnasts, coaches, clubs and competition organisers using the app.

* [Features](features.md) - Everything the trampoline tariff calculator can do, in plain language for gymnasts, coaches, clubs and competition organisers.
* [Routine builder guide](routine-guide.md) - Step-by-step instructions for gymnasts and coaches, covering how to add skills, build and check a routine, work on a competition level, write your own requirements, and view, print and share routines. Also as a [PDF](routine-guide.pdf).
* [Competitions guide](competition-guide.md) - Step-by-step instructions for competition organisers, club competition secretaries, members, coaches and individual entrants, covering how to run a competition, run a club, enter, and sign off routines. Also as a [PDF](competition-guide.pdf).

Both PDFs are built by `scripts/guide-pdfs.py`; run it again whenever a guide changes.

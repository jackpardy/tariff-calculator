# Domain

* [Skill model](skill-model.md) - How a trampoline skill is represented (rotation, twist per phase, shape, take-off, direction, seat landing) and the rules derived from it, such as landing position, shape relevance, FIG notation, naming and repetition.
* [Tariff (difficulty) calculation](tariff.md) - How a skill's difficulty is computed under the FIG Code of Points 2025–2028 §17, pinned by all 139 of the Code's worked examples.
* [Routine validation](routine-validation.md) - How a routine is checked against the Code of Points (repeats, transitions, interruptions, the tenth skill, the ten-element limit) and which skills count towards the total.
* [Execution judging](execution.md) - How execution judges assess a skill under the FIG Code of Points 2025–2028 (shape, legs, arms, opening, twist, landing) and how the app works out which deductions apply to any skill from its attributes, for the "How it's judged" pop-up.
* [Skill catalog and search](skill-catalog.md) - The common skills with their official names, how the picker groups them into tabs, and how search finds skills by name, alias or FIG notation.
